# 2026 全国大学生电子设计竞赛开源项目索引

本仓库由华侨大学 AIoT 协会维护，用于汇总成员参与 2026 年全国大学生电子设计竞赛（NUEDC）的开源代码、硬件资料和项目文档。

> 本仓库只维护项目索引，不集中存放各队完整工程。每个队伍或成员应在 `HQU-AIot` 组织内创建独立仓库并自行维护。

## 仓库命名建议

建议使用：

```text
2026-nuedc-题号-队伍简称
```

例如：`2026-nuedc-a-vision-car`。

## 每个项目仓库至少应包含

- `README.md`：项目简介、题号、队伍成员、软硬件环境、构建与运行方法。
- `LICENSE`：明确开源许可证；推荐根据依赖和团队意愿选择 MIT、Apache-2.0 或 GPL-3.0。
- `src/`：主要代码，或保留原开发工具所需的清晰工程结构。
- `docs/`：设计说明、调试记录、关键参数和复现步骤。
- `hardware/`：原理图、PCB、BOM 等硬件资料（如适用）。
- 必要的依赖版本、工具链版本和安全注意事项。

不要提交密钥、账号口令、访问令牌、个人隐私数据，或没有再分发权限的比赛资料和第三方文件。

## 收录流程

1. 在 `HQU-AIot` 组织内创建独立的公开仓库。
2. 按上述要求整理代码、文档和许可证。
3. 在本仓库提交“项目收录申请”Issue，并填写项目仓库地址等信息。
4. 维护者核验仓库可访问、说明完整且无明显敏感信息后，将项目加入本页索引。

详细要求见 [CONTRIBUTING.md](CONTRIBUTING.md)。

## 权限说明

- 项目创建者负责管理自己的独立仓库。
- 组织普通成员对其他成员的仓库默认只有读取权限，不能直接修改。
- 本索引仓库由维护者更新；其他成员通过 Issue 或 Pull Request 提交收录申请。
- 如需多人共同维护某个项目仓库，由该仓库管理员按最小权限原则单独授权或建立团队。

## 免责声明

各项目由对应贡献者维护。项目资料仅用于学习、交流和技术复现，不代表竞赛官方结论。使用代码或硬件设计前，请自行检查许可证、依赖、安全性和适用性。
